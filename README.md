# 回声档案 ECHO ARCHIVE

> 每个选择，都会留下痕迹。

面向 12–16 岁学生的多人互动情绪教育叙事原型。4–6 名玩家在 AI DM「管理员·零」的引导下完成三幕故事，在家庭、学业、师生、同伴与网络生活等情境中识别情绪、表达立场，并看见选择的后果。

**当前版本是本地规则引擎演示，不连接真实大模型，不采集真实学生身份，也不生成心理诊断或霸凌风险等级。**

## 运行

```bash
npm install
npm run dev      # 本地开发
npm run build    # 类型检查 + 生产构建
npm run preview  # 预览 dist
```

技术栈：Vite + React 19 + TypeScript（strict）+ Tailwind CSS v4 + React Router（HashRouter）+ Zustand persist。

## 核心流程

1. 选择故事 → 2. 设置人数与时长 → 3. 领取角色（先公开档案，后私人档案）→ 4. 打印折叠角色档案 → 5. AI DM 导入场景与任务 → 6. 玩家讨论并选择行动 → 7. 状态更新与剧情反馈 → 8. 打印行动回执 / 事件证据 → 9. 进入下一幕 → 10. 三幕后生成结局 → 11. 重演关键节点 → 12. 对照两条路径 → 13. 教师复盘 → 14. 学习总结并退出角色。

## 核心机制

### 状态与选择

- 四个连续状态：紧绷 `tension` / 信任 `trust` / 公开 `openness` / 安全 `safety`，取值 0–100。
- 每个关键事件提供 3–5 个行动，每个行动有自己的意图、虚构状态变化、线索与反馈。
- 不做「好行为 +1 / 坏行为 −1」的道德评分；结局由多个选择共同决定。
- 状态只属于虚构角色与虚构班级，界面全程标注「不是对真实玩家的心理测评」。

### 结局

A 故事根据紧绷、信任、公开、安全与选择标记，生成五种结局之一：

- `repair` 被修补的名单
- `silent` 安静的胜利
- `tear` 第二个空格
- `exposed` 公开的代价
- `echo` 留下的回声

B/C 根据 `open` / `guard` 标记生成演示结局，并明确标注「演示片段」。

### 重演

每个幕开始时保存一份快照（状态、标记、线索）。重演时：

1. 选择历史节点；
2. 查看当时掌握的信息与状态；
3. 选择一个未选过的行动；
4. 保留该节点之后的其他选择，重算状态与结局；
5. 在对照页并排比较两版路径，并可打印「重演对照」。

第一次路径永远不会被覆盖。

### 打印材料

| 编号 | 材料 | 生成时机 |
| --- | --- | --- |
| PRT/01 | 角色档案 | 领取角色时；沿虚线折叠，上半公开、下半私人 |
| PRT/02 | 事件证据 | 获得线索时；与线索编号一一对应 |
| PRT/03 | 行动回执 | 作出选择后；记录行动、行动者、意图与状态变化 |
| PRT/04 | 重演对照 | 重演后；记录两次选择、两版结局与状态差异 |

打印流程：打印提示 → 热敏纸模拟动画 → 纸张预览 → 保存打印记录 / 再次打印 / 浏览器打印 / 返回剧情。浏览器打印使用 `#print-portal` 与专用打印样式，避免把整个应用界面打印出来。

## 设计系统

- 底色：纸面 `#eae8e2`、档案纸 `#f5f3ed`、墨色 `#191a1c`。
- 强调：低饱和红 `#8a3a31`、黄铜 `#8a7b66`。
- 质感：双线边框、硬阴影、半调网点、扫描线、热敏纸、打字机、档案印章。
- 字体：标题宋体/衬线，正文保持中文可读；像素感只用于标题与编号。
- 版式：菜单、台账、表单、档案墙、视觉小说、事件报告、时间线各自不同，不套同一套卡片网格。
- 无高饱和渐变、玻璃拟态或科技蓝紫。

## 数据与隐私

- 本局进度保存在浏览器 localStorage（键：`echo-archive-session-v1`）。
- 不包含真实学生姓名、账号、聊天记录或心理测量数据。
- 教师端只读取同一台设备上的本局虚构进度。
- 「学习总结 → 退出角色并清除本机记录」会清除角色、选择、线索、打印记录与重演结果，并需要二次确认。

## 扩展说明

### 接入真实 AI

前端只提交结构化的故事状态（当前幕、已发生选择、已获得线索）到自有服务端；服务端持有 API 密钥、调用模型、做结构化校验与内容安全过滤，再把结果返回前端。**API 密钥不得写入前端。** 当前所有叙述来自本地预写分支。

### 接入真实热敏打印

将 `MaterialSheet` 转为 58mm 热敏打印指令，通过本地打印服务或蓝牙/USB 驱动输出。需要处理纸张宽度、折行、条形码、离线重试与打印队列去重。

### 多设备课堂

真实课堂需要一局一个会话码、每名玩家独立设备、教师端只读汇总，并对角色私人档案做端到端隔离。

### 补齐 B/C 故事

需要补齐三幕、分支结局、线索库与重演快照，并保持与 A 相同的打印材料结构。
